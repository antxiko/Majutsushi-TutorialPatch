# Traduccion al ingles de Hai no Majutsushi: la tabla que lee tools/traduce.py.
# Las cuentas y de donde sale cada direccion: traduccion/inventario.md.

# FUENTE DE 16 PUNTOS (p00:5ACD). Un texto entre comillas se parte en casillas de dos letras
# (alfabeto Konami 8 x 8 al doble); con '|' las casillas son los trozos: de 1-2 letras anchas, de
# 3 estrechas (10 puntos) o de 4 mas estrechas (8 puntos). {XX} = el codigo XX tal cual.
#
#   grupo NOMBRE banco=B cpu=BASE huecos=DESDE-HASTA[,...] [banco2=B cpu2=BASE huecos2=...]
#       las cadenas del grupo se colocan en sus huecos (los bytes viejos de las cadenas japonesas)
#   cadena ref=B:DIR[,B:DIR...] "TEXTO"            DIR = la palabra que apunta a la cadena
#   bloque ref=B:DIR  XX,YY "TEXTO" | XX,YY "TEXTO" ...   registros X, Y, texto, 0xFF seguidos
#
# LETRAS REDIBUJADAS: los codigos que el juego pinta sueltos (cifras, han, vientos...).
#   letra XX "TEXTO" [centro]          letra XX copia NN[+MM] = la letra NN del cartucho (+ la
#                                      mitad izquierda de MM a la derecha)
#   reserva XX[-YY] ...                letras que no se tocan
#
# TILES 8 x 8 (p00:5363). Cambios en su sitio, mismos bytes:
#   tiles B:DIR ORIGINAL = NUEVO     NUEVO: "LETRAS" enteras de la hoja (A-Z, 0-9), {AB} un tile
#                                    con dos letras estrechas, 00 un tile en blanco
#   nombre ORIGINAL = NUEVO          cambia el nombre en todas las listas de nombres
#
# OTROS: byte B:DIR VIEJO = NUEVO    un byte de codigo (un contador que cambia)
#
# Anchos medidos (ventana y X del texto): menu del modo 4 casillas, 半荘終了 4 (ventana
# 0x58-0xA8, texto en 0x60), 続行/終了 2 (texto en 0x78), yaku 8 (0x30 a 0xB0), estilo 2.

# Las tablas 0x6640, 0x664E y 0x6664 se quedan. Lo que no cabe en p01 va al final de p04 (0xFF de
# cola desde 0xBF97), pero la rutina de texto (p00:5ACF) pone los bancos 5-6 para cada letra y al
# volver deja los 1-2-3: una cadena del banco 4 solo se lee bien hasta la primera letra. Por eso
# las tres llamadas que escriben nombres de las tablas (p04:A9B0 yaku, AE1E el 0x35, AA41 limites)
# pasan por una rutina nueva en p04:BF97 que copia la cadena a la pila y la escribe desde alli:
#   push ix / ld ix,-16 / add ix,sp / ld sp,ix / push ix / push de
#   1: ld a,(hl) / ld (ix+0),a / inc hl / inc ix / inc a / jr nz,1b
#   pop de / pop hl / call 5AB1 / ld hl,16 / add hl,sp / ld sp,hl / pop ix / ret
# La linea de fu y han (p04:A9F5, con su color por p00:5AB8) no pasa por ella: solo=1.
bytes 4:BF97 libre = DD E5 DD 21 F0 FF DD 39 DD F9 DD E5 D5 7E DD 77 00 23 DD 23 3C 20 F6 D1 E1 CD B1 5A 21 10 00 39 F9 DD E1 C9
